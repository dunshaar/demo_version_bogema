# Богема — демонстрационный сайт

Самостоятельная публикация локальной версии сайта от 18 октября 2026 года.

- Сайт: https://dunshaar.github.io/demo_version_bogema/
- Репертуар: https://dunshaar.github.io/demo_version_bogema/repertoire/
- GitHub Pages публикует корень ветки `main`. Сборка не требуется: обычные HTML, CSS и JavaScript.
- Для локального просмотра запустите статический HTTP-сервер из корня репозитория.

В репозитории находятся страницы и необходимые медиа: четыре видео, фотографии, значки и локальные шрифты с лицензиями. Архивы, резервные копии и исходные съёмки не включены. Отдельный клиентский репертуар с выбором песен сюда не входит.

Форма работает в демонстрационном режиме без доставки заявок. Сервер и юридические документы подключаются отдельным этапом. Параметры транспорта находятся в `forms-config.json`; секреты нельзя помещать в клиентские файлы.

Предыдущий опубликованный сайт `demo_version_bogem` и исходная локальная копия не изменены.

## Оптимизация видео

Все четыре видео сохранены в H.264/MP4 с исходным разрешением и частотой кадров. Аудиодорожки скопированы без перекодирования; совпадение с оригиналами проверено по SHA-256 аудиопакетов. MP4 подготовлены для потокового старта (`faststart`).

Суммарный вес видео: 126,2 → 74,6 МиБ (−40,9%). Оригиналы сохранены в исходной локальной папке.

## Единая дизайн-система — 20 октября 2026

Общие токены и элементы трёх интерфейсов находятся в `assets/bogema-design-system.css`. Значения, роли и порядок синхронизации отдельной клиентской страницы описаны в [docs/bogema-design-system.md](docs/bogema-design-system.md). Клиентская страница остаётся локальной и в этот репозиторий не включена.
