# Богема — демонстрационный сайт

Текущая локальная версия подготовлена к публикации 22 октября 2026 года.

- Главная: https://dunshaar.github.io/demo_version_bogema/
- Публичный репертуар: https://dunshaar.github.io/demo_version_bogema/repertoire/
- Выбор песен для клиентов: https://dunshaar.github.io/demo_version_bogema/selection/

GitHub Pages публикует корень ветки main. Сайт статический: HTML, CSS, JavaScript, отдельная сборка не требуется. Файл .nojekyll сохранён.

## Страница выбора

Папка selection/ — самостоятельная страница для передачи ссылки клиенту. Ссылок на неё с главной и публичного репертуара нет. Noindex не является авторизацией: страница открывается по известному адресу.

Рабочая клиентская папка остаётся отдельной. Перед выпуском её содержимое синхронизируется в selection/ командой:

~~~sh
python3 tools/sync-client-selection.py --client-root "/absolute/path/to/client/public"
~~~

Скрипт переносит только файлы сайта; --check сверяет копию. Сохранение статусов отделено по пути страницы, чтобы соседние проекты GitHub Pages не использовали один черновик. Имя и телефон в хранилище не сохраняются.

Исходный статус песен — «Можно». «Очень хочу» выделено латунным цветом, «Не надо» — приглушённым красным. Выбор работает без диалогов восстановления; сброс применяется сразу.

## Формы

Доставка заявок и пожеланий отключена: enabled=false, endpoint=null. Формы не имитируют успешную отправку. Сервер, юридические документы и рабочая доставка подключаются отдельным этапом.

## Медиа

Включены фотографии, значки, локальные шрифты с лицензиями и четыре видео. Видео — H.264/MP4 с исходным разрешением и частотой кадров; аудиодорожки скопированы без перекодирования. Общий вес видео ранее уменьшен с 126,2 до 74,6 МиБ, faststart сохранён. В этом выпуске медиа не перекодировались.

Архивы, резервные копии, исходные съёмки и локальные журналы проверок в выпуск не включены. Прежний сайт demo_version_bogem не изменяется.
